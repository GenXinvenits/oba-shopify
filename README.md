# OBA Shopify

Custom Shopify theme for the Oregon Badminton Academy Pro Shop.

## Direction

The redesign connects the Pro Shop to the OBA academy brand: **Train. Play. Compete.** The storefront is designed to feel like a performance badminton shop rather than a generic catalog.

Official brand site: https://orbadminton.com/
Store: https://oregonbadminton.com/

## Current build

- Local-first Shopify theme structure
- OBA announcement bar
- Sticky responsive header/navigation
- Performance-led hero section
- Shop-by-category cards
- Dynamic collection/product cards
- Custom product page
- Custom cart page
- OBA academy story section
- Authorized-brand strip for Yonex, Victor, Hundred and Yang Yang
- Newsletter signup
- Responsive CSS and lightweight JavaScript

## Important

Product, collection, pricing and inventory data remain in Shopify. The theme only controls presentation and storefront behavior.

Do not hard-code catalog counts. Public collection counts can differ from the currently published/available storefront catalog.

## Development

Use Shopify CLI against the store's development theme. Do not publish directly to the live theme until the complete storefront has been reviewed.
